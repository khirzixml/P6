# Deskripsi Materi Praktikum 6 Query Lanjutan

Pada praktikum ini dipelajari berbagai perintah SQL lanjutan yang digunakan untuk mengolah data pada database. Materi berfokus pada penggunaan query untuk menampilkan, mengelompokkan, memperbarui, dan mengurutkan data di dalam tabel database secara lebih spesifik dan efisien.

Beberapa materi yang dipelajari antara lain:

### 1. `SELECT DISTINCT`

Perintah ini digunakan untuk menampilkan data yang bernilai unik dari suatu kolom pada tabel. Fungsi utama dari query ini adalah menghilangkan data yang duplikat sehingga hasil yang ditampilkan hanya data yang berbeda saja.

### 2. `SELECT AVG ... GROUP BY`

Materi ini membahas penggunaan fungsi agregat `AVG()` untuk menghitung nilai rata-rata dari data numerik. Query dikombinasikan dengan `GROUP BY` agar perhitungan rata-rata dapat dilakukan berdasarkan kategori atau kelompok tertentu.

### 3. `UPDATE ... WHERE`

Perintah `UPDATE` digunakan untuk mengubah atau memperbarui data yang sudah ada di dalam tabel database. Dengan tambahan `WHERE`, perubahan data dapat dilakukan secara spesifik sesuai kondisi tertentu sehingga data lain tidak ikut berubah.

### 4. `UPDATE` dengan Beberapa Kondisi

Pada bagian ini dipelajari cara memperbarui data menggunakan lebih dari satu kondisi dalam query. Teknik ini berguna untuk melakukan perubahan data yang lebih detail dan tepat sasaran.

### 5. Perubahan Data Alamat

Materi ini menerapkan perintah `UPDATE` untuk mengganti alamat lama menjadi alamat baru berdasarkan identitas tertentu, misalnya ID karyawan. Tujuannya agar data pada database tetap akurat dan terbaru.

### 6. `ORDER BY ASC`

Perintah ini digunakan untuk menampilkan data dari tabel dan mengurutkannya secara menaik (ascending), misalnya dari huruf A–Z atau angka terkecil ke terbesar. Query ini memudahkan pengguna dalam membaca dan menganalisis data.

---

## Kesimpulan

Praktikum Query Lanjutan memberikan pemahaman mengenai cara mengelola data database menggunakan perintah SQL yang lebih kompleks. Dengan mempelajari query seperti `DISTINCT`, `AVG`, `GROUP BY`, `UPDATE`, dan `ORDER BY`, pengguna dapat melakukan pengolahan data secara lebih efektif, terstruktur, dan sesuai kebutuhan sistem informasi.
